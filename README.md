## 当前预装题库

- 马克思主义基本原理：合并题库 + 导论/第一章至第七章分章题库。

C1 驾照题库已从当前预装数据中移除。

## 主观题规则

材料分析题、论述题和简答题使用文本作答。练习模式提交后显示参考答案，由用户点击“掌握 / 未掌握”自评；考试模式交卷后显示参考答案，但这些主观题不参与自动得分、正确率或及格判断。

## iPhone 添加到主屏幕

访问 GitHub Pages 链接：<https://334379.github.io/shiroha-mayuan-site/>。

在 iPhone Safari 中打开后，点击分享按钮，选择“添加到主屏幕”。添加完成后会以独立窗口打开，并缓存当前预装的马原与习概题库，便于离线刷题。
